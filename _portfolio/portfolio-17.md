**Timeline:** September 2026

- **Project Description:** Prometheus is a small suite of AI tools. Its first tool, Socrates, takes a book as a PDF, EPUB, DOCX, TXT or Markdown file and returns a structured summary: the core argument, key themes, a chapter-by-chapter breakdown, takeaways and the passages worth quoting. The text is extracted in the browser, so the file itself never leaves your device. Built with TypeScript, React and Vite.
