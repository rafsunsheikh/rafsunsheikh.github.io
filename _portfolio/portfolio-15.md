**Timeline:** June 2026 - Present

- **Project Description:** GSO-1 is a local application registry and launcher. It finds every project on your computer, shows whether each one is running and healthy, and starts any of them with one click. It also includes the Ops Room, a dashboard for your Claude Code sessions, a local LLM tab, scheduled jobs, and access from your phone over Tailscale. Built with Python (FastAPI) and a desktop shell.
