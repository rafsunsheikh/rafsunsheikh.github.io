**Timeline:** October 2026 - Present

- **Project Description:** vizdesk is a terminal app that reads CSV or Excel files, tells you what needs cleaning, and suggests the charts a data scientist would draw first, each with the reason and the numbers behind it. It finds the target column (such as churn, survived or price) and shows what goes with it, offers 66 chart types, and draws publication-ready PNGs with alt text and a matching Python script. There is no LLM inside: every suggestion comes from fixed rules and statistics, so it runs offline, gives the same answer every time, and never sends your data anywhere. Built with Python.
